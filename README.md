A single original line, at most 200 characters, describing a hilariously useless superpower — written by `main.py` to `/output/entry.txt`.

> I can fly, but only three inches off the ground and only downhill, so my commute is still technically walking.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
